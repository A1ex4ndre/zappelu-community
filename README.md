# Zappelu Community

Welcome to the community for **Zappelu** (working name), a proprietary macOS TV and radio receiver app.

Use **Discussions** for questions, tips, feedback, and feature ideas. Use **Issues** to report bugs; include your macOS version, app version, and steps to reproduce.

This repository contains community information only. Zappelu’s app source code remains private and is not included here.

Please remove personal information, credentials, and private stream URLs before posting logs or screenshots.
